# smallfidelity.services

Static site for GitHub Pages. Deployed at https://smallfidelity.services.

## Files
- `index.html` — the site
- `CNAME` — custom domain declaration for GitHub Pages
- `404.html` — catch-all redirect to homepage
- `<slug>/index.html` and `<slug>.html` pairs — redirect stubs for the old
  GoDaddy Website Builder URLs. Meta refresh + `rel=canonical` + JS backup.
